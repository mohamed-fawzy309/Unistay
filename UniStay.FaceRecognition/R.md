## 🎯 نظرة عامة | Overview

### الوصف
نظام متكامل للتعرف على الوجوه وتسجيل الحضور تلقائياً باستخدام تقنيات الذكاء الاصطناعي والرؤية الحاسوبية.

### الميزات الرئيسية
- ✅ التعرف على الوجوه في الوقت الفعلي
- ✅ تسجيل حضور تلقائي
- ✅ نظام غياب ذكي (كل الطلاب غائبين افتراضياً)
- ✅ واجهة رسومية حديثة وسهلة الاستخدام
- ✅ تقارير وإحصائيات مفصلة
- ✅ تصدير البيانات إلى CSV
- ✅ دعم اللغة العربية والإنجليزية

### التقنيات المستخدمة
- **Python 3.11+** - لغة البرمجة الأساسية
- **OpenCV** - معالجة الصور والفيديو
- **YuNet** - كشف الوجوه (Face Detection)
- **SFace** - التعرف على الوجوه (Face Recognition)
- **Tkinter** - الواجهة الرسومية
- **NumPy** - معالجة المصفوفات
- **PIL/Pillow** - معالجة الصور

## 🔧 المكونات الأساسية | Core Components

### 1️⃣ Backend - الخلفية

#### A. نماذج الذكاء الاصطناعي (AI Models)

**🔍 YuNet - Face Detection**
```python
الموقع: model/yunet.py
الوظيفة: كشف الوجوه في الصور
المدخلات: صورة RGB بحجم 640x480 (قابل للتعديل)
المخرجات: مواقع الوجوه [x, y, w, h, confidence]
الدقة: 95%+
السرعة: ~30 FPS على CPU
```

**👤 SFace - Face Recognition**
```python
الموقع: model/sface.py
الوظيفة: التعرف على هوية الوجه
المدخلات: صورة وجه محصصة (aligned face)
المخرجات: vector بحجم 128 بُعد (feature vector)
طريقة المقارنة: Cosine Similarity
العتبة الافتراضية: 0.363 (قابلة للتعديل)
الدقة: 97%+
```

#### B. أدوات المعالجة (Utilities)

**face_utils.py**
```python
# الدوال الرئيسية:

1. extract_all_features(image)

   - استخراج الخصائص (features) لكل وجه
   - الإرجاع: [(feature_vector, bbox), ...]

2. match_with_db(feature, database)
   - مقارنة وجه مع قاعدة البيانات
   - إيجاد أفضل تطابق
   - الإرجاع: (name, score, is_match)
```

## 🤖 نماذج الذكاء الاصطناعي | AI Models

### YuNet - Face Detection

```
الاسم: face_detection_yunet_2023mar_int8.onnx
الحجم: ~6 MB
الإصدار: March 2023
التكميم: INT8 (سريع، دقة جيدة)

المعاملات القابلة للتعديل:
┌────────────────────┬──────────┬─────────────┐
│ المعامل            │ الافتراضي│ النطاق      │
├────────────────────┼──────────┼─────────────┤
│ input_size         │ 640x480  │ 160x120     │
│                    │          │ - 1920x1080 │
│ conf_threshold     │ 0.6      │ 0.1 - 0.95  │
│ nms_threshold      │ 0.3      │ 0.1 - 0.7   │
│ top_k              │ 5000     │ 100 - 10000 │
└────────────────────┴──────────┴─────────────┘

الأداء:
- CPU (Core i5): ~30 FPS @ 640x480
- GPU: ~120 FPS @ 640x480
- دقة الكشف: 95%+
```

### SFace - Face Recognition

```
الاسم: face_recognition_sface_2021dec_int8.onnx
الحجم: ~36 MB
الإصدار: December 2021
التكميم: INT8

المعاملات:
┌────────────────────┬──────────┬─────────────┐
│ المعامل            │ الافتراضي│ الوصف       │
├────────────────────┼──────────┼─────────────┤
│ disType            │ 0        │ 0=Cosine    │
│                    │          │ 1=L2        │
│ threshold_cosine   │ 0.363    │ عتبة القبول │
│ threshold_norml2   │ 1.128    │ عتبة L2     │
└────────────────────┴──────────┴─────────────┘

الأداء:
- Feature Extraction: ~5ms
- Matching: <1ms
- دقة التعرف: 97%+
- False Positive Rate: <2%
```

## 📖 كيفية الاستخدام | How to Use

### السيناريو الأول: تسجيل طلاب جدد

```
1. افتح التطبيق → python app.py

2. انتقل إلى تبويب "📝 Register Student"

3. أدخل البيانات:
   - Student ID: رقم الطالب (مثال: 2021001)
   - Student Name: اسم الطالب (مثال: أحمد محمد)

4. اضغط "📷 Start Capture"

5. وجه الطالب للكاميرا
   - سيتم التقاط 20 صورة تلقائياً
   - تحرك قليلاً لتنويع الزوايا

6. اضغط "💾 Save Student"

7. الطالب تم تسجيله ✓
```

### السيناريو الثاني: تسجيل الحضور

```
1. افتح التطبيق

2. انتقل إلى "📹 Real-Time Recognition"

3. اضغط "▶ Start Recognition"

4. الطلاب يقفون أمام الكاميرا واحد تلو الآخر

5. عند التعرف:
   - "✓ SUCCESS: أحمد محمد marked at 08:30:15"
   - العلامة تتحول من ❌ إلى ✓ في Student Management

6. الحضور يُسجل تلقائياً في attendance.csv
```

### السيناريو الثالث: مراجعة الحضور


## ⚠️ استكشاف الأخطاء | Troubleshooting

### خطأ: الكاميرا لا تعمل

```
الأعراض: شاشة سوداء أو "Camera not available"

الحلول:
1. تحقق من توصيل الكاميرا
2. غيّر camera_index من Settings:
   - جرب 0, 1, 2, 3
3. تحقق من أذونات الكاميرا في النظام
4. أغلق التطبيقات الأخرى التي تستخدم الكاميرا
```

### خطأ: النماذج غير موجودة

```
الأعراض: "Model file not found"

الحلول:
1. تحقق من وجود مجلد models/
2. تأكد من وجود الملفات:
   - face_detection_yunet_2023mar_int8.onnx
   - face_recognition_sface_2021dec_int8.onnx
3. حمّل النماذج من:
   https://github.com/opencv/opencv_zoo
```

### خطأ: التعرف غير دقيق

```
الأعراض: يتعرف على الشخص الخطأ

الحلول:
1. زِد recognition_threshold من Settings:
   - من 0.6 إلى 0.7 أو 0.75
2. أعد تسجيل الطالب بصور أفضل
3. تأكد من إضاءة جيدة
4. استخدم دقة كاميرا أعلى
```

### خطأ: البرنامج بطيء

```
الأعراض: FPS منخفض، تأخير في الاستجابة

الحلول:
1. قلل دقة الكاميرا:
   - من 1280x720 إلى 640x480
2. قلل FPS Limit:
   - من 60 إلى 30 أو 20
3. أغلق البرامج الأخرى
4. استخدم نسخة GPU من OpenCV (متقدم)
```

### خطأ: الملفات لا تُحفظ

```
الأعراض: البيانات تُفقد بعد إغلاق البرنامج

الحلول:
1. تحقق من صلاحيات الكتابة على مجلد database/
2. تأكد من وجود مساحة كافية
3. تحقق من عدم وجود برنامج antivirus يمنع الحفظ
4. شغّل البرنامج كـ Administrator (Windows)
```
